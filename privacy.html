Data practices

Privacy policy

Last updated: October 28, 2026

Hermes Gmail Automation is a personal Gmail integration maintained by Hisham on Windows. This policy describes that local installation and this public information website. The integration is not a hosted public service and has no public sign-up.

Gmail access and purpose

The owner connects the Gmail account using Google OAuth. The integration requests gmail.modify, which permits reading, composing and sending messages, and changing labels and mailbox state, including moving messages to Trash. This scope does not permit immediate permanent deletion that bypasses Trash.

Depending on the workflow, processed data can include message bodies, attachments, sender and recipient addresses, other message metadata, and labels. Hermes uses this data to carry out the owner's requested email tasks, such as searching, summarizing, preparing replies, sending authorized messages, and organizing the mailbox.

Where processing happens

Hermes runs on the owner's Windows computer, with Ollama as the normal local model. Gmail access requires requests to Google's Gmail API. Google OAuth client information and tokens are stored in protected local Hermes files; they are not placed on this public website.

The public website is static. It has no Gmail connection, credential form, analytics, advertising trackers, or embedded third-party assets. On GitHub Pages, GitHub processes ordinary website request information and logs visitors' IP addresses for security purposes. This hosting activity does not give the website or GitHub Pages access to the connected Gmail account. See the GitHub Privacy Statement for its practices.

Local storage and retention

Email content and derived information may be retained locally in agent conversations, logs, and workflow outputs. Retention depends on the owner's configuration and workflows, and this data may remain until the owner deletes it. Local credentials are retained to support the authorized account connection.

The owner can delete retained local email data and remove local OAuth files. Removing the integration's Google Account access prevents further authorized account access, but does not by itself remove copies already retained locally or messages already sent.

Sending and external integrations

Email is sent only through workflows and to recipients the owner authorizes. Sending delivers message content to those recipients through Gmail.

Configured external integrations may receive relevant email content or derived data when the owner instructs them to. If the owner selects an external model provider instead of local Ollama, data sent to that provider is processed under its own terms and privacy practices. Local operation therefore does not mean that every workflow keeps all data on the computer.

Google API data use

Hermes Gmail Automation's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements. For this personal integration, Gmail data is used to provide the owner's email workflows. Transfers to configured services require the owner's authorization and must support those workflows. Gmail data is not sold or used for advertising.

Access, deletion, and security

The owner can stop workflows and revoke the application's account access from the third-party connections or permissions area of their Google Account. Retained local data can be deleted separately by the owner. Device access controls and the local Hermes configuration affect the protection of local files and credentials.
